General Questions

What is Motionix?

Motionix is a premium marketplace for GSAP‑powered web animation templates. We provide ready‑to‑use components that help developers and designers create stunning animations quickly.

Are the templates free?

We offer both free and paid templates. Each template clearly displays its price. Free templates are fully functional and can be used in personal projects.

What license do the templates have?

All templates are licensed under a commercial license, allowing you to use them in personal, educational, and commercial projects without additional fees.

Do I need to know GSAP?

Basic knowledge of GSAP is helpful but not required. Our templates are designed to be plug‑and‑play, with clear comments and documentation for easy customisation.

Technical Questions

How do I install a template?

After purchase, you'll receive a ZIP file containing HTML, CSS, and JavaScript files. Simply extract and include them in your project. Full installation instructions are included in the documentation.

Can I modify the templates?

Absolutely! You can customize colours, timing, easing, and even add new elements. The code is well‑commented to help you make changes easily.

Do templates work on all browsers?

Yes, our templates are tested on all modern browsers (Chrome, Firefox, Safari, Edge) and are responsive across devices.
